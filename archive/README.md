# Archived assets

`sounds` contains the unused audio variants previously stored in `.unused/sounds`.
The files were moved without modification. Source-labelled filenames in `found`
retain their existing provenance clues; no new licensing claim is implied.

These assets are not imported by the application or copied into releases.
Active audio remains under `website/sounds`. Keep source names intact when they
provide provenance, rather than renaming archived binary files for code style.
